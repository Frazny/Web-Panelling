🤖 Wispbyte'da Bot'u Çalıştırma Rehberi

bot-panel.zip hazır — şimdi panelde 6 adım. Her adımda neye tıklayacağın resimli.

1

Files sekmesine gir, klasöre GİRME

  • Sol menüden Files'e tıkla (bu, sunucunun ana dizini = /home/container)
  • Açılan ekranda discordbot klasörünü göreceksin — onun içine GİRME!
  • Ana ekranda kal.

2

Upload ile bot-panel.zip'i yükle

  • Sağ üstteki Upload butonuna tıkla (tek dosya yüklenir, klasör değil)
  • Bilgisayarından DiscordBot\deploy\bot-panel.zip dosyasını seç
  • Yükleme çubuğunun bitmesini bekle

3

Zip'i Extract et

  • bot-panel.zip satırındaki üç nokta (⋮) menüsüne tıkla
  • Açılan menüden Extract'e tıkla
  • Açılan pencerede "Extract to" alanını BOŞ bırak → Extract de
  • Bu, zip'i ana dizine açar (dosyalar herhangi bir klasöre gömülmez)
▼

4

Sonucu doğrula, boş klasörü sil

Doğrulama
  • Extract sonrası ana dizinde şunlar görünmeli: main.py, config.json, cogs/, utils/, data/, requirements.txt
  • discordbot boş klasörünü artık silebilirsin (seç → ⋮ → Delete)

5

Startup komutunu ayarla

  • Üst menüden Startup sekmesine geç
  • Startup Command alanına şunu yaz:
python main.py
  • Eğer alan zaten varsa sadece doğru yazıldığından emin ol → Save de

6

Console'dan Start'a bas

  • Console sekmesine geç
  • Sağ alttaki Start (yeşil ▶) butonuna bas
  • Console'da Bot giriş yaptı yazısını gör → başarılı! 🎉
  • Artık PC'deki botu kapatabilirsin
$ python main.py
Sunucu komutları senkronize edildi: 24 komut
Bot giriş yaptı: MyBot#1234 (ID: 123456789)
Sunucular: ['Sunucu Adım']
⚠

Hata olursa: "ModuleNotFoundError: discord"

Sık karşılaşılan

İlk start'ta bağımlılıklar yüklü olmayabilir. Console'da şunu yazıp Enter'a bas, sonra tekrar Start:

pip install -r requirements.txt

Kurulum birkaç dakika sürebilir. Kurulum bitince yukarıdaki ▶ Start'a tekrar bas.
